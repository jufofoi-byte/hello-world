# 🪥 치아요정 덧니의 양치 대작전

책 **《우리 동네에 이런 치과가 있으면 좋겠다》**에 나오는 치아요정 **덧니**와 함께 충치균을 닦아내는 어린이용 양치 게임입니다.
설치 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다. (PC 마우스, 스마트폰 터치 모두 지원)

## 놀이 방법

두 가지 모드가 있습니다.

- **손가락으로 닦기**: 화면 속 이빨을 칫솔로 문지르는 게임
- **카메라로 진짜 닦기**: 전면 카메라로 얼굴을 인식해 입 주변에서 칫솔이 움직이는지 보고, 덧니가 6구역(위/아래 × 오른쪽 어금니·앞니·왼쪽 어금니)을 차례로 안내합니다

1. **양치 시작!** 버튼을 누릅니다.
2. 칫솔을 **꾹 누른 채**로 이빨 위를 쓱싹쓱싹 문지르면 충치균이 사라집니다.
3. **2분** 안에 16개 이빨을 모두 깨끗하게 만들면 별 3개!
4. 가끔 **충치대장**(보라색 왕관 세균)이 나타납니다. 그 이빨을 재빨리 닦아 쫓아내지 않으면 이빨이 다시 더러워져요.
5. 게임이 끝나면 **아침 / 점심 / 저녁** 양치 도장을 받고, 도장판(최근 7일)에 기록됩니다.

## 홈 화면에 앱으로 추가하기

- **iPhone(Safari)**: 공유 버튼 → **홈 화면에 추가**
- **Android(Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

한 번 열어 두면 오프라인에서도 실행됩니다.

## 카메라 모드는 어떻게 동작하나

- Google MediaPipe 얼굴 랜드마크 모델(`vendor/`, `models/`)을 브라우저 안에서 실행해 입 위치를 잡습니다. 영상은 기기 밖으로 나가지 않습니다.
- 입술 윤곽점 20개를 조금 키운 모양을 치아 영역으로 잡고, 그 안에서 프레임 간 밝기 변화를 재서 칫솔이 움직이는지 판단합니다(`mouth-motion.js`). 고개가 조금 움직이거나 말하는 정도는 움직임으로 치지 않고, 천천히 닦아도 인식됩니다.
- 6구역(위/아래 × 오른쪽 어금니·앞니·왼쪽 어금니)은 덧니가 치과 순서로 20초씩 안내하고, 닦는 동안 안내 중인 구역이 깨끗해집니다. 충치대장이 나타나면 그 구역이 우선입니다.
- 처음 실행 시 모델(약 13MB)을 내려받아 몇 초 걸립니다. 이후엔 캐시됩니다.

## 특징

- 상황에 따라 바뀌는 덧니의 픽셀아트 표정 17종 (`assets/deotni/`)
- 웹 오디오로 만든 쓱싹 소리, 딩동 효과음, 팡파르 (소리 끄기 가능)
- 도장판은 브라우저 `localStorage`에 저장 (서버 없음)
- 외부 라이브러리 없이 HTML 한 파일로 동작
- PWA 지원: 앱 아이콘(`icons/`), 매니페스트, 오프라인 캐시(`sw.js`)

## 실행

```bash
# 그냥 파일을 열거나
open index.html

# 또는 간단한 로컬 서버로
python3 -m http.server 8000   # http://localhost:8000
```

GitHub Pages를 켜면 그대로 웹에서 플레이할 수 있습니다.
