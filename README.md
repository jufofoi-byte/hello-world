# 🪥 치아요정 덧니의 양치 대작전

치아요정 **덧니**와 함께 충치균을 닦아내는 어린이용 양치 게임입니다.
설치 없이 `index.html`을 브라우저에서 열면 바로 실행됩니다. (PC 마우스, 스마트폰 터치 모두 지원)

## 놀이 방법

1. **양치 시작!** 버튼을 누릅니다.
2. 칫솔을 **꾹 누른 채**로 이빨 위를 쓱싹쓱싹 문지르면 충치균이 사라집니다.
3. **2분** 안에 16개 이빨을 모두 깨끗하게 만들면 별 3개!
4. 가끔 **충치대장**(보라색 왕관 세균)이 나타납니다. 그 이빨을 재빨리 닦아 쫓아내지 않으면 이빨이 다시 더러워져요.
5. 게임이 끝나면 **아침 / 점심 / 저녁** 양치 도장을 받고, 도장판(최근 7일)에 기록됩니다.

## 특징

- 상황에 따라 바뀌는 덧니의 픽셀아트 표정 17종 (`assets/deotni/`)
- 웹 오디오로 만든 쓱싹 소리, 딩동 효과음, 팡파르 (소리 끄기 가능)
- 도장판은 브라우저 `localStorage`에 저장 (서버 없음)
- 외부 라이브러리 없이 HTML 한 파일로 동작

## 실행

```bash
# 그냥 파일을 열거나
open index.html

# 또는 간단한 로컬 서버로
python3 -m http.server 8000   # http://localhost:8000
```

GitHub Pages를 켜면 그대로 웹에서 플레이할 수 있습니다.
